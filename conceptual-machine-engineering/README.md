A methods synthesis using explicit realization contracts to distinguish preserved observations, conformance, resource bounds, evidence obligations, and permission to enact a transition.

## Evidence and limitations

The paper provides elementary conditional arguments, counterexamples, and a bounded illustration. It does not establish a new universal theory, comparative engineering effectiveness, independent replication, machine-checked proof, hardware performance, or production security validation. Independent reconstruction and comparative studies remain future work.
