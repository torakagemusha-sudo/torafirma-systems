# Gizmos

Small, self-contained utilities and status widgets for the public surface of this repository.

| Gizmo | Purpose |
|-------|---------|
| `badges.md` | Ready-to-paste shields.io / static badges for READMEs |
| `status-board.md` | Human-readable surface status board |
| `certificate-check.sh` | Local check that Arithmetic Clock certificates are present |
| `visibility-hint.md` | How this repo links to Academia + torafirma.com visibility trackers |

These are meta tools. They do not alter mathematical claims.
