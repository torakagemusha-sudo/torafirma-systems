# Support

## What this repository is for

- Independent **verification** and **reproduction** of published reference material
- Constructive technical questions about claim boundaries, certificates, and evidence

## What it is not

- A general support channel for commercial products
- A place to request private source, patents, or unpublished substrates

## Channels

| Need | Channel |
|------|---------|
| Verification / reproduction report | GitHub issue → “Verification / Reproduction Report” |
| Research clarification | GitHub issue → “Research Question” |
| Product / partner enquiry | https://torafirma.com/contact |
| Academia papers | https://independent.academia.edu/ThomasHelm3 |

## Response expectations

Issues are reviewed on a best-effort basis. Reciprocal good faith (attribution, accurate representation, respect for stated licences) is expected.
